# Qwen3.5 GDN recurrence, one simdgroup per value column (mlx-lm's decomposition) vs gdn_chunk_forward and
# gdn_recurrent, Apple M5 Pro, 2026-10-27/28. INTERIM: runs 1, 2, 2b below; the final clean run is appended after them.
#
# Lane: branch gp/w32-gdn-simd-recurrent off main 789a132. Kernels in kernels/qwen35_gdn.metal, host in
# src/qwen35.rs (gdn_recurrent_simd*), A/B rig tests/qwen35_gdn_simd_ab.rs, mlx comparator
# bench/qwen35_gdn_mlx_kernel_probe.py. Nothing here is called by Qwen35Model.
#
# Shape: batch 1, 16 key heads, 16 value heads, Dk = Dv = 128 (Qwen3.5-2B), non-zero per-batch start state,
# state_out written, f32 operands, gates/l2norm/q scale computed by every arm (chunked arm's prep dispatch is inside
# its time; the "pre" simd arms' prep dispatch is inside theirs). Inputs identical for every arm.
# Protocol: one sample = N launches between two synchronize()s divided by N (N sized per arm to ~20 ms, <= 400);
# 3 untimed warmup launches per arm; 22 rounds; arm order rotates by one each round; every arm's output and state is
# compared with gdn_recurrent's before any timing and the run aborts above 1e-4 of scale (all arms agreed to ~1e-7).
# Noise floor: gdn_recurrent timed twice (arms "Recurrent" and "RecurrentAgain"); the per-round ratio's median/range
# is printed as "noise". Run 1 and run 2 time the library default (every launch its own submit-and-wait);
# run 2b times with async encode on (launches queue back to back), which is the only protocol that resolves T = 1.
#
# CONDITIONS (stated honestly): none of these three runs had an idle GPU. Device utilization at the hold start was
# 37% (run 1), 27% (run 2) and 40% (run 2b), and 34-41% just before the A/B; CPU load average 9 / 44 / 20 (2b rose to
# 43 during the hold). The machine lock was held (other sessions run their GPU work under it, so the residue is work
# outside the lock). Ratios inside one interleaved run share that contamination; absolute milliseconds do not
# transfer. gdn_chunk_forward and gdn_recurrent land within ~7% of their 2026-10-27 one-shot values
# (8.03 / 14.48 ms at T = 8192 in qwen35_gdn_packed_oneshot_m5pro.txt on branch gp/w27-attn-bf16-prefill), run 2b's min
# (8.32 / 17.03) is 3% / 18% above them.
#
# Naming: "simd L<n>" = n lanes share a value column (32 = mlx's mapping: 4 state rows a lane, simd_sum;
# 16 / 8 = two / four columns a simdgroup, 8 / 16 rows a lane, shuffle-xor butterfly). "pre" = gates, norms, q scale
# computed once per (token, value head) by qwen35_gdn_simd_prep into a float4 scratch, rather than recomputed by every
# column in the loop; adds one dispatch. "vec" = q and k loaded as float4s (lane holds a contiguous run of rows;
# host requires ld/q_off/k_off multiples of 4). "pf" = step t+1's operands loaded before step t's arithmetic.
# "sg8" = 8 simdgroups a threadgroup instead of 4. All variants: 4 simdgroups a threadgroup except sg8.
