# (confirmed with the peer session). The machine was on battery (80%,

# slower than the plugged-in measurements in docs/qwen35.md (exact step 7.2 s,
# cross-entropy 1768 ms), so compare the two runs here with each other, not
# with those.

# 345 tokens/s) and the cross-entropy with gradients from 4042 to 1114 ms
# (3.6x); peak footprint 25.5 / 25.8 GB, max RSS 20.0 / 20.1 GB. Every weight
# is still cast to bf16 per GEMM call (forward, recompute, backward); the
# estimate that would have made a per-step bf16 weight cache worth building
# was a ratio below ~1.7x (bf16 ~3.2 s against 7.2 s, +30%), and 2.44x is
# above it, so the cache stays deferred.
